# Contributing Knowledge

PKL treats a contribution as an auditable evidence package, not simply a fact to be added to a list.

For each proposed claim, provide:

```text
Claim:
Evidence:
Source:
What does the evidence actually establish?
Known contradictions:
Provenance:
Why do you consider the evidence independent?
```

## Contribution principles

- Cite the underlying source wherever possible.
- Distinguish an original source from reporting about that source.
- Do not count repeated reporting as independent confirmation without provenance evidence.
- State limitations and uncertainty.
- Include credible contradictory evidence when you know it exists.
- Avoid arguments from authority: a respected contributor is not itself evidence.
- Keep claims precise enough to be tested or challenged.

During the pilot, contributions should be submitted as GitHub pull requests or issues. The goal is to discover weaknesses in the model before building a larger public ingestion interface.

Contributors are expected to welcome challenge and correction. A challenged claim is not a failed contribution; challenge is part of the intended PKL workflow.
